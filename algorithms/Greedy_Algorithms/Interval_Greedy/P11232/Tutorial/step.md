## Step 0　开题侦察（前 15 分钟，不做题）

- **动作**：通读 4 题的「描述首段 + 数据范围 + 特殊性质表」，给每题打「模型熟悉度」「实现难度」两个标签，决定做题顺序。
- **产出**：草稿纸上的时间表。
- **铁律**：任何一题卡住 **20 分钟**无实质进展 → 立刻转「写暴力拿部分分」，之后再回来。

## Step 1　读题形式化

- **动作**：
  1. 逐句把故事翻译成数学定义，写出**判定谓词** `over(对象, 位置) → bool`；
  2. 圈注关键词：超过/不低于（`>` vs `>=`）、可正可负可为零（分类信号）、驶入驶出也测速（端点包含性）、多组数据（清空）、注意精度（禁浮点）；
  3. **手玩样例**：把「样例解释」逐行核对——它是出题人写给你的分步推导，读透等于半个题解；
  4. 搭好 I/O 骨架，先让程序能读入、能输出占位结果。
- **产出**：形式化定义 + 关键词表 + 样例手算表 + 可编译的骨架。
- **常见事故**：漏掉「严格大于」、漏掉端点测速、漏掉多组数据。

## Step 2　复杂度预算（数据范围反推）★最硬的启发式★

| 规模 n | 可行复杂度 | 算法族 |
| :-- | :-- | :-- |
| ≤ 10 | O(n!) / O(2^n·n) | 暴搜、全排列 |
| ≤ 20~24 | O(2^n·n) / O(3^n) | 状压 DP、折半搜索 |
| ≤ 100 | O(n³) | Floyd、区间 DP |
| ≤ 3000~5000 | O(n²) | 二维 DP、暴力枚举区间 |
| ≤ 1e5~1e6 | O(n log n) / O(n) | 排序+贪心、二分、线段树、单调栈 |
| ≤ 1e9 | O(√n) / O(log n) | 数论分块、二分答案、矩阵快速幂 |

- **辅助维度**：值域小 → 桶/差分/筛；值域大但 n 小 → 离散化；空间 256MB → `int` 总量约 6e7。
- **用法**：预算先排除不可能的算法，再**反推出必须成立的结构性质**（如「每车只能 O(log m)」⟹ 必须二分 ⟹ 必须单调）。

## Step 3　子任务逆向工程

- **动作**：把测试点表逐行翻译成「部分分路线图」。特殊性质的并集 ≈ 正解的分类讨论框架。
- **实施顺序（永不跳步）**：`O(nm) 暴力 → 交一次 → 加特殊性质分支 → 交一次 → 合并优化 → 最终提交`。
- **产出**：阶段—得分表。每一步都可提交、可回退。

## Step 4　结构挖掘 → 构造 IR（中间表示）

依次问「**结构六问**」：

1. 能否**降维**？有没有一条轴（位置/时间/下标/值域）承载全部判定？
2. 判定关于这条轴**单调**吗？
3. 每个对象的可行集合是**连续区间**吗？
4. 有没有**可加性**（前缀和/差分）？
5. 决策有没有**后效性**？无 → DP 状态怎么定义？
6. 交换两个决策的顺序，答案会变好吗？→ 贪心 + 排序关键字

- **产出**：`vector<IR>`，把 n 个原始对象压缩成算法层能直接吃的形式（区间集 / 事件集 / DP 状态 / 图）。
- **调试黄金法则**：**先把 IR 打印出来对样例**。IR 是唯一中间层，错误只可能在它之前（建模错）或之后（算法错）。

## Step 5　归约到模型

| 题面触发词 | 模型 | 标准算法 |
| :-- | :-- | :-- |
| 最少点覆盖所有区间 / 最多关闭 | 区间打点 | 按**右端点**排序 + 贪心 |
| 最多不相交区间 | 区间调度 | 按右端点排序 + 贪心 |
| 最大的最小值 / 最小的最大值 | 二分答案 | 二分 + 贪心 check |
| 覆盖次数 / 区间并 | 差分 / 扫描线 | 排序 + 前缀 |
| 计数 + 取模 | 组合数学 | 容斥、DP 计数 |
| 开关状态且 n ≤ 20 | 状压 | O(2^n·n) |

## Step 6　正确性论证（写代码前 3 分钟）

| 算法 | 必须自证 |
| :-- | :-- |
| 贪心 | 排序关键字为何？**交换论证**；用 3 个反例攻击（换关键字能否破） |
| DP | 状态无后效性；转移完备不重复；边界与不可达值 |
| 二分答案 | `check(x)` 单调；边界与终止条件 |
| 数学/构造 | 小规模暴力枚举验证公式 |

## Step 7　分层实现

```
① I/O 层  →  ② 建模层（原始数据 → IR，唯一含题意的一层）  →  ③ 算法层（纯算法）  →  ④ 输出层
```

- **解耦的价值**：部分分 → 正解只需替换 ② 层；对拍时可用暴力 ② 层验证高效 ② 层。
- **固化习惯**：默认 `long long`；数组开 `n+5`；下标 `1..m` 用 `0` / `m+1` 当哨兵；容器用局部变量（自动清空）；比较器用 `<` 不用 `<=`；链上 DFS 改迭代；`(x%mod+mod)%mod`。

## Step 8　审计 + 对拍（最后 30 分钟）

**交卷前 12 项审计**

```
□ freopen 文件名与题目英文名完全一致     □ 编译无 error（-O2 -Wall）
□ 所有乘法/求和已 long long              □ > 与 >= 、开闭区间、lower/upper_bound
□ 数组大小 vs 数据范围；二维总量 vs 内存  □ 多组数据全部重置
□ 空集 / n=1 / 全相等值 / 端点重合        □ 递归深度是否达 1e5
□ 输出格式：空格、换行、几个数、取模      □ 调试输出全部删除
□ 所有样例通过（含特殊性质样例）          □ 极限数据计时 < 时限 70%
```

**对拍三件套**：① 随机/边界生成器（刻意造：等号成立、端点重合、空集、中途终止、n=1）② 绝对可信的暴力解 ③ 正解；不一致时**打印 IR 定位**。

**故障分诊**：WA → 查 IR 与严格性；TLE → 查是否还是 O(nm)；MLE → 查二维总量与递归栈；RE → 查越界与爆栈；**0 分 → 先查 freopen 文件名**。
