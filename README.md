# NOI_prac_encyclopedia

**A Personal Repository for Informatics Olympiad Preparation and Competitive Programming**

## Overview

**NOI_prac_encyclopedia** is a personal repository dedicated to the systematic study and preparation for the **National Olympiad in Informatics (NOI)** and related competitive programming competitions.

The repository serves as a centralized archive of algorithm implementations, problem solutions, historical contest materials, reference resources, and study notes accumulated throughout my informatics olympiad preparation.

Its primary purpose is to organize learning materials, document problem-solving experiences, and establish a comprehensive, continuously maintained knowledge base for competitive programming.

## Repository Contents

The repository includes the following categories of materials:

### 1. Problem Solutions
- Personal solutions to competitive programming problems.
- Problems from CSP-S, NOIP, NOI, USACO, and other competitions.
- Practice problems from Luogu and other online judges.
- Alternative approaches and optimization techniques for selected problems.

### 2. Algorithm Templates
- Fundamental algorithms and data structures.
- Graph theory and graph algorithms.
- Dynamic programming and greedy algorithms.
- Searching, sorting, and computational techniques.
- String algorithms, mathematics, and number theory.
- Advanced algorithms and data structures.

### 3. Historical Contest Materials
- Past contest problems and official statements.
- Historical examination papers and related resources.
- Official solutions, editorials, and reference implementations, where available.
- Additional materials relevant to informatics olympiad preparation.

### 4. Study Notes and References
- Algorithm explanations and theoretical notes.
- Problem-solving strategies and methodological summaries.
- Common implementation techniques and optimization methods.
- Reference materials for systematic review and further study.

## Objectives

This repository is maintained with the following objectives:

- Establish a structured and accessible archive of competitive programming resources.
- Develop a comprehensive understanding of algorithms and data structures.
- Document personal progress in problem-solving and algorithmic implementation.
- Support systematic preparation for CSP-S, NOIP, NOI, and related competitions.
- Provide a long-term reference for continued study and review.

## Programming Language

The primary programming language used in this repository is **C++**, with implementations generally following the C++14 and C++17 standards.

## Maintenance and Attribution

This repository is maintained as an ongoing personal learning project. Its structure and contents may be revised, expanded, or reorganized as new materials are collected and additional topics are studied.

Unless otherwise specified, source code in the problem-solving and algorithm-template sections represents my own implementations or adaptations developed during practice.

Historical contest materials, official problem statements, editorials, and other third-party resources remain the intellectual property of their respective authors and organizations. Where applicable, original sources and attribution will be provided.

The inclusion of external resources is intended solely for educational reference and non-commercial study.
